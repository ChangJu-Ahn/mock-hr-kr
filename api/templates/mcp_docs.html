MCP가 뭔가요? What is MCP?

MCP(Model Context Protocol)는 AI 에이전트가 외부 시스템의 기능을 발견하고 호출하기 위한 개방형 표준입니다. 사람이 읽는 REST 문서와 달리, MCP 서버는 자신이 제공하는 도구(tool) 목록과 각 도구의 JSON Schema를 tools/list로 직접 알려줍니다. 에이전트는 이 스펙만 보고 어떤 인자를 넣어야 하는지 스스로 판단해 tools/call로 실행합니다.

이 페이지의 모든 내용은 별도로 작성한 문서가 아니라 실행 중인 MCP 서버 객체에서 뽑아낸 것입니다. 도구가 추가·변경되면 이 문서도 자동으로 따라갑니다. 원본 스펙은 /mcp-docs/spec.json에서 JSON으로 받을 수 있습니다.
