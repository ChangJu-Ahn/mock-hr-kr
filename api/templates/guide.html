사용법 & 업무 흐름 Guide

이게 뭔가요? What is this?

일반적인 인사관리 시스템(HRIS)을 흉내 낸 목업 HR입니다. 하나의 SQLite DB를 세 가지 창구로 노출합니다: 사람용 웹 콘솔, 에이전트용 REST API, 에이전트용 MCP 서버. 콜드 스타트마다 데이터가 새로 시딩됩니다. 데모 전용이라 실제 보안은 없습니다.

전체 흐름 Overall flow

  1. 입사 (Hire) — 부서·직급을 지정해 사원을 등록합니다. 등록 시 당해연도 연차가 자동 부여되고 입사 발령이 함께 기록됩니다.
  2. 교육 (Training) — 법정필수·직무·리더십·어학 과정을 수강신청하고 이수/미이수 처리합니다. 법정필수 이수율이 대시보드에 집계됩니다.
  3. 연차·휴가 (Leave) — 휴가를 신청(신청)하고 승인/반려합니다. 승인 시 잔여 연차가 차감되며, 잔여가 부족하면 승인이 차단됩니다.
  4. 근태 (Attendance) — 출근/퇴근을 기록하면 근무·연장 시간과 상태(지각/조퇴/정상)가 자동 계산됩니다.
  5. 인사발령 (Appointment) — 승진·부서이동·휴직·복직·퇴직을 기록하면 사원정보(직급/부서/재직상태)에 즉시 반영됩니다.

Hire ─▶ (연차부여+입사발령) ─▶ Training / Leave(승인시 연차차감) / Attendance ─▶ Appointment(사원정보 반영)

에이전트 연결 Agent access

REST와 MCP는 헤더 X-API-Key: changjuahn가 필요합니다. 웹 콘솔과 /api/docs는 공개입니다.

REST (Employee·Department·Position·Course·Training·Appointment):

curl -H "X-API-Key: changjuahn" https://<fqdn>/api/employees
curl -X POST -H "X-API-Key: changjuahn" -H "Content-Type: application/json" \
     -d '{"name":"홍길동","dept_code":"D110","position_code":"P1"}' https://<fqdn>/api/employees

MCP (Attendance·Leave), streamable HTTP at /mcp with the same header. Tools: log_attendance, list_attendance, get_attendance_summary, submit_leave_request, decide_leave_request, get_leave_balance, list_leave_requests, list_employees, get_employee.

Full REST reference: /api/docs.
